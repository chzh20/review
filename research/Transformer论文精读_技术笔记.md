## 一、论文背景与定位

- **Transformer** 是继 **MLP**、**CNN**、**RNN** 之后的**第四大类神经网络模型**，被认为是近三年深度学习领域最重要的工作之一。

## 三、摘要解读

摘要的核心逻辑链：

1. **现状**：主流**序列转录模型**（Sequence Transduction Model，即输入一个序列、输出另一个序列，如机器翻译）依赖复杂的**循环神经网络（RNN）**或**卷积神经网络（CNN）**，并采用 **Encoder-Decoder 架构**。
2. **已有改进**：性能最好的模型中，编码器与解码器之间已引入**注意力机制（Attention）**。
3. **本文贡献**：提出一个新的**简单架构**——**Transformer**，仅依赖注意力机制，不使用循环或卷积层。
4. **实验结果**：
   - 在 WMT 2014 **英德翻译**上达到 **28.4 BLEU**，比当时最优结果好 **2 个 BLEU**。
   - 在**英法翻译**上，单模型超越所有模型（包括集成模型）。
   - 仅在 **8 个 GPU** 上训练 **3.5 天**。
5. **泛化性**：Transformer 架构可泛化到其他任务。

> **补充说明**：
> - **BLEU Score**：机器翻译领域常用的自动评估指标，衡量机器翻译输出与参考翻译的 n-gram 重合度，分数越高越好。
> - 论文强调 "simple" 一词在当前研究中已从贬义转为褒义——只要结果好，简洁的架构更受欢迎（如 ResNet）。

## 四、结论要点

1. Transformer 是**第一个仅使用注意力机制**的序列转录模型，将所有循环层替换为 **Multi-Headed Self-Attention**。
2. 在机器翻译任务上，训练速度和最终效果均优于其他架构。
3. 作者对纯注意力模型的前景表示激动，展望将其应用于**文本以外的数据**（图片、语音、视频），以及**减少生成的时序化**。
4. 代码开源在 **tensor2tensor** 库中。

> **补充**：现代论文通常将代码链接放在摘要最后一句，以便读者快速复现。本文将代码信息放在结论末尾，反映了当时的写作惯例。

## 五、导言（Introduction）

### 5.1 RNN 的特点与缺陷

- 2017 年时序模型的主流是 **RNN**（包括 **LSTM** 和 **GRU**）。
- RNN 的核心机制：对序列从左到右逐步计算，第 t 时刻的**隐藏状态 h_t** 由上一时刻的 **h_{t-1}** 和当前输入 **x_t** 共同决定，从而将历史信息逐步传递。

**RNN 的两大缺陷：**

| 缺陷 | 说明 |
|------|------|
| **难以并行** | 计算 h_t 必须等待 h_{t-1} 完成，序列长度为 n 则需时序执行 n 步，无法充分利用 GPU/TPU 的并行能力，导致计算性能差 |
| **长程信息丢失** | 历史信息逐步传递，时序较长时早期信息可能丢失；若增大 h_t 维度以保留更多信息，则每个时间步都需存储，内存开销大 |

> 尽管已有诸多改进（并行化方法、分解方法等），但本质上未根本解决问题。

### 5.2 Attention 在 RNN 中的应用

- 在本文之前，Attention 已被成功用于 **Encoder-Decoder 之间**，主要解决如何将编码器的信息有效传递给解码器的问题。
- 但此时的 Attention 与 RNN 是**配合使用**的，并非纯注意力模型。

### 5.3 Transformer 的提出

- 完全抛弃循环层，**纯基于注意力机制**。
- 因为 Attention 可以完全并行（本质是矩阵乘法），所以并行度高，训练时间更短。

## 六、相关工作（Related Work）

### 6.1 用 CNN 替换 RNN 的尝试

- CNN 替换 RNN 可减少时序计算，但存在**长序列建模困难**的问题：卷积每次只看局部窗口（如 3×3），相距较远的元素需要多层卷积才能融合。
- Transformer 的 Attention 每次能看到**整个序列**，一层即可全局建模。

### 6.2 多头注意力的灵感来源

- CNN 的优势在于**多输出通道**，每个通道可识别不同模式。
- 为模拟这一效果，Transformer 提出 **Multi-Head Attention（多头注意力）**，通过多次投影到不同子空间来匹配不同模式。

### 6.3 自注意力机制

- **Self-Attention** 并非本文首创，此前已有工作提出。
- 本文的创新在于：**Transformer 是第一个仅依赖自注意力来构建 Encoder-Decoder 架构的模型**。

## 七、模型架构（Model Architecture）

### 7.1 Encoder-Decoder 架构概述

- **编码器（Encoder）**：将长度为 n 的输入序列 (x_1, ..., x_n) 编码为同样长度为 n 的向量序列 (z_1, ..., z_n)，其中 z_t 是 x_t 的向量表示。
- **解码器（Decoder）**：接收编码器的输出，生成长度为 m 的输出序列 (y_1, ..., y_m)。n 和 m 可以不等长。
- **自回归（Auto-Regressive）**：解码器逐个生成输出，生成 y_t 时以之前所有输出 (y_1, ..., y_{t-1}) 作为输入——即**过去的输出也是当前的输入**。

### 7.2 Transformer 整体结构

```
输入 → Embedding + Positional Encoding
         ↓
    [Encoder × N]  ←─ Multi-Head Self-Attention + Feed-Forward + Residual + LayerNorm
         ↓
    [Decoder × N]  ←─ Masked Multi-Head Attention + Cross Attention + Feed-Forward + Residual + LayerNorm
         ↓
    Linear + Softmax → 输出
```

- Encoder 和 Decoder 各由 **N=6** 个相同层堆叠而成。
- 每层输出维度固定为 **d = 512**（Base 模型），方便残差连接（残差连接要求输入输出维度一致）。

> **设计哲学**：整个模型只需调两个核心参数——**层数 N** 和 **模型宽度 d**，其余参数按比例推算。这一简洁设计深刻影响了后续的 BERT、GPT 等模型。

---

### 7.3 编码器（Encoder）

每个 Encoder 层包含**两个子层**：

1. **Multi-Head Self-Attention（多头自注意力）**
2. **Position-wise Feed-Forward Network（逐位置前馈网络，即 MLP）**

每个子层的计算流程：

```
output = LayerNorm(x + Sublayer(x))
```

即：**残差连接（Residual Connection）** + **Layer Normalization**。

> **补充**：残差连接由 ResNet 提出，将输入直接加到输出上（x + Sublayer(x)），缓解深层网络的梯度消失问题。

---

### 7.4 解码器（Decoder）

每个 Decoder 层包含**三个子层**：

1. **Masked Multi-Head Self-Attention（带掩码的自注意力）**
2. **Cross-Attention（交叉注意力）**：Key 和 Value 来自编码器输出，Query 来自解码器上一层输出
3. **Position-wise Feed-Forward Network（MLP）**

同样使用残差连接 + LayerNorm。

**Mask 的作用**：
- 解码器是自回归的，预测第 t 时刻输出时不能看到 t 时刻之后的输入。
- 但 Attention 机制会看到所有输入，因此通过 **Mask** 将 t 时刻之后的注意力分数设为极大的负数（如 -1e10），经过 Softmax 后权重变为 0。
- 这保证了**训练与预测时行为一致**。

---

### 7.5 LayerNorm vs BatchNorm

这是理解 Transformer 的关键概念之一。

#### BatchNorm（批归一化）

- 对每个**特征（列）**在 mini-batch 内计算均值和方差，将其归一化为均值 0、方差 1。
- 训练时使用 mini-batch 统计量；预测时使用全局存储的均值和方差。
- 还会学习缩放参数 γ（可调整归一化后的均值和方差）。

#### LayerNorm（层归一化）

- 对每个**样本（行）**计算均值和方差进行归一化。
- 可理解为将数据转置后做 BatchNorm，再转置回来。

#### 三维输入的情况（Transformer 的实际场景）

输入形状为 `(batch, sequence, feature)`，即 `(batch, n, d)`：

| 归一化方式 | 切片方向 | 特点 |
|-----------|---------|------|
| **BatchNorm** | 沿 batch 和 sequence 维度切片，对每个 feature 归一化 | 样本长度变化大时，均值方差抖动大；预测时遇到比训练时更长的样本，全局统计量可能不适用 |
| **LayerNorm** | 沿 feature 维度切片，对每个样本独立归一化 | 不依赖其他样本，无需存储全局统计量，对变长序列更稳定 |

> **结论**：在变长序列模型中，LayerNorm 比 BatchNorm 更稳定，因此 Transformer 选用 LayerNorm。
>
> **补充**：后续研究表明，LayerNorm 有效的根本原因更多在于对**梯度的归一化**和**提升训练稳定性**，而非原文给出的解释。

---

### 7.6 注意力机制（Attention）

#### 7.6.1 一般化定义

注意力函数将一个 **Query** 和一组 **Key-Value 对**映射为输出：

- **输出** = Value 的加权和（输出维度与 Value 相同）
- **权重** = Query 与对应 Key 的**相似度**（不同的相似度函数产生不同的注意力变体）

#### 7.6.2 Scaled Dot-Product Attention（缩放点积注意力）

这是 Transformer 使用的注意力计算方式，也是**最简单的注意力机制**：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

**计算步骤**：

1. Query 与每个 Key 做**内积**，得到相似度分数。
2. 除以 **√d_k**（d_k 为 Key 的维度）进行缩放。
3. 经过 **Softmax** 得到非负且和为 1 的权重。
4. 将权重与 Value 相乘求和，得到输出。

**矩阵形式**（高效并行计算）：

```
Q (n × d_k)  ×  K^T (d_k × m)  →  分数矩阵 (n × m)
                                     ↓ ÷ √d_k
                                     ↓ Softmax（按行）
                                  权重矩阵 (n × m)
                                     ↓ × V (m × d_v)
                                  输出矩阵 (n × d_v)
```

> 整个计算只需两次矩阵乘法，高度可并行。

#### 7.6.3 为什么要除以 √d_k？

- 当 d_k 较大时，点积值的绝对值可能很大，导致 Softmax 输出趋近于 **one-hot**（最大值接近 1，其余接近 0）。
- 此时**梯度趋近于 0**（Softmax 在极端值处梯度极小），导致训练停滞。
- 除以 √d_k 将点积值缩小到合理范围，保持梯度的有效性。

> **补充**：d_k = 512 时，√d_k ≈ 22.6，缩放效果显著。

#### 7.6.4 两种常见注意力机制对比

| 类型 | 说明 | Query/Key 是否等长 |
|------|------|-------------------|
| **加性注意力（Additive Attention）** | 通过一个小型前馈网络计算相似度 | 可不等长 |
| **点积注意力（Dot-Product Attention）** | 通过内积计算相似度 | 需等长 |

Transformer 选用点积注意力（加缩放），因为**实现简单、计算高效**（仅需矩阵乘法）。

---

### 7.7 多头注意力（Multi-Head Attention）

#### 动机

- Scaled Dot-Product Attention 本身**无可学习参数**（相似度函数就是内积）。
- 为了识别不同的模式（类似 CNN 的多输出通道），需要引入可学习的参数。

#### 做法

1. 将 Q、K、V 分别通过 **h 组可学习的线性投影矩阵**（W_Q, W_K, W_V）投影到低维空间。
2. 在每个投影空间中独立计算 Scaled Dot-Product Attention。
3. 将 h 个头的输出 **拼接（Concat）** 后，再通过一次线性投影（W_O）得到最终输出。

**公式**：

$$
\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)
$$

$$
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h) W^O
$$

**实际参数（Base 模型）**：

- 头数 **h = 8**
- 每个头维度 = d / h = 512 / 8 = **64**
- 8 个头的输出拼接后恰好恢复为 512 维

> **补充**：虽然看起来是很多小矩阵乘法，但实际实现中可通过一次大矩阵乘法完成。

---

### 7.8 Transformer 中注意力的三种使用方式

| 使用位置 | Query 来源 | Key/Value 来源 | 特点 |
|---------|-----------|---------------|------|
| **Encoder Self-Attention** | 编码器输入自身 | 编码器输入自身 | 自注意力，每个位置可看到所有位置 |
| **Decoder Masked Self-Attention** | 解码器输入自身 | 解码器输入自身 | 带 Mask，只能看到当前及之前的位置 |
| **Encoder-Decoder Cross-Attention** | 解码器上一层的输出 | 编码器的最终输出 | 解码器根据当前状态从编码器输出中"提取"相关信息 |

**Cross-Attention 的直觉**：以英译中为例，解码器生成"好"字时，Query 会与编码器中 "hello" 对应的向量相似度更高（赋予更大权重），而与 "world" 相似度较低。即根据解码器的当前需求，从编码器的信息中**选择性提取**相关内容。

---

### 7.9 Position-wise Feed-Forward Network（逐位置前馈网络）

- 本质是一个**单隐藏层的 MLP**，对序列中每个位置（词）独立且相同地作用。
- **结构**：线性层 → ReLU → 线性层

```
输入 (d=512) → W1 → 隐藏层 (d_ff=2048) → ReLU → W2 → 输出 (d=512)
```

- 中间隐藏层维度扩大 **4 倍**（512 → 2048），输出再投影回原维度。

> **关键理解**：Attention 层负责**汇聚序列全局信息**（aggregation），MLP 负责**将信息映射到更合适的语义空间**。因为 Attention 已经完成了序列信息的整合，所以 MLP 可以对每个位置独立处理。

#### Transformer 与 RNN 的信息传递对比

| 模型 | 序列信息传递方式 | 语义空间转换 |
|------|----------------|-------------|
| **RNN** | 将上一时刻的**输出**作为下一时刻的**输入**，逐步传递历史信息 | 共用一个线性层/MLP |
| **Transformer** | 通过 **Attention 层**全局拉取整个序列的信息 | 每个 Position 独立使用 MLP |

---

### 7.10 Embedding 层

- 将输入的**词（Token）**映射为长度为 d（=512）的向量。
- Transformer 中有三处使用 Embedding：
  1. 编码器输入
  2. 解码器输入
  3. Softmax 前的线性层
- **三处共享权重**，简化训练。
- Embedding 权重乘以 **√d**：因为 Embedding 学习过程中向量的 L2 范数会趋小（如学到 1），而后续要加上 Positional Encoding（其值在 [-1, 1] 之间），乘以 √d 使两者在**相似的数值尺度**上相加。

---

### 7.11 Positional Encoding（位置编码）

#### 为什么需要位置编码？

- Attention 机制是**顺序不变的（permutation-invariant）**：打乱输入序列的顺序，输出值不变（仅顺序变化）。
- 但在时序数据处理中，词序对语义至关重要。
- RNN 天然包含时序信息（上一时刻输出传入下一时刻）；Attention 不包含，因此需要**在输入中显式加入位置信息**。

#### 实现方法

- 使用不同周期的 **sin 和 cos 函数**为每个位置生成一个长度为 d（=512）的向量。
- 将位置编码向量与 Embedding 向量**相加**，完成时序信息的注入。
- 因为 sin/cos 的值域为 [-1, 1]，所以 Embedding 乘以 √d 使两者尺度匹配。

> **直觉类比**：计算机用 32 个 bit 表示一个整数；Positional Encoding 用 512 维向量（sin/cos 函数值）表示一个位置编号。

## 八、为什么使用 Self-Attention（第四章）

论文通过一张表比较了四种层在三个维度上的表现：

| 层类型 | 计算复杂度 | 顺序操作数 | 最大路径长度 |
|--------|-----------|-----------|------------|
| **Self-Attention** | O(n²·d) | O(1) | O(1) |
| **RNN（循环层）** | O(n·d²) | O(n) | O(n) |
| **CNN（卷积层）** | O(k·n·d²) | O(1) | O(log_k(n)) |
| **Self-Attention (restricted)** | O(r·n·d) | O(1) | O(n/r) |

**说明**：
- n = 序列长度，d = 向量维度，k = 卷积核大小，r = 受限注意力的邻居范围。
- **计算复杂度**：Self-Attention 为 O(n²·d)，RNN 为 O(n·d²)。当 n ≈ d（实际中两者都在数百到数千），复杂度相当。
- **顺序操作数**：Self-Attention 和 CNN 为 O(1)（高度可并行），RNN 为 O(n)（必须逐步计算）。
- **最大路径长度**：Self-Attention 为 O(1)（任意两个位置一步可达），RNN 为 O(n)（信息需逐步传递，长距离易丢失），CNN 为 O(log_k(n))（需多层卷积）。

> **关键洞察**：Self-Attention 对模型的假设更少（归纳偏置更弱），因此需要**更多数据和更大模型**才能达到与 RNN/CNN 同等效果——这是现代 Transformer 模型越来越大的根本原因。

## 九、实验设置（第五章）

### 9.1 数据集

| 任务 | 数据集 | 规模 | 字典 |
|------|--------|------|------|
| 英→德翻译 | WMT 2014 | 450 万句对 | 37,000 token（BPE，英德共享） |
| 英→法翻译 | 更大数据集 | — | — |

> **BPE（Byte-Pair Encoding）**：将词拆分为子词单元（词根 + 变化后缀），减小字典规模，使编码器与解码器可共享 Embedding。

### 9.2 硬件与训练时间

| 模型 | 硬件 | 每步时间 | 总步数 | 总时间 |
|------|------|---------|--------|--------|
| Base | 8 × P100 GPU | 0.4 秒 | 100,000 步 | 12 小时 |
| Big | 8 × P100 GPU | 1.0 秒 | 300,000 步 | 3.5 天 |

> **补充**：此后 Google 推动内部转向 TPU（适合大矩阵乘法），本文在一定程度上推动了这一进程。

### 9.3 优化器与学习率

- **优化器**：Adam（β1=0.9, β2=0.98, ε=10⁻⁹）
- **学习率调度**（无需手动调参）：

$$
lr = d_{\text{model}}^{-0.5} \times \min(\text{step}^{-0.5}, \text{step} \times \text{warmup}^{-1.5})
$$

- 包含 **Warmup** 阶段（warmup_steps = 4000）：学习率先线性增大，后按步数的 -0.5 次方衰减。
- 学习率与模型宽度的 -0.5 次方成正比——模型越宽，学习率越低。

### 9.4 正则化

使用了**两种正则化**：

1. **Residual Dropout（残差 Dropout）**
   - 对每个子层（Multi-Head Attention 和 MLP）的输出，在进入残差连接和 LayerNorm 之前施加 Dropout。
   - 对 Embedding + Positional Encoding 的和也施加 Dropout。
   - Dropout 率：Base 模型 = 0.1，Big 模型 = 0.3。

2. **Label Smoothing（标签平滑）**
   - 将正确标签的目标值从 1.0 降低到 **0.1**，其余概率分配给其他类别（0.9 / 字典大小）。
   - **代价**：会增加 Perplexity（模型不确定度上升）。
   - **收益**：提升精度和 BLEU 分数（这才是最终关心的指标）。
   - 该技术由 Inception v3 推广。

> **补充**：Softmax 难以输出精确的 1.0（需 logit 趋近无穷大），Label Smoothing 缓解了这一训练困难。

### 9.5 超参数对比（Base vs Big）

| 超参数 | Base 模型 | Big 模型 |
|--------|----------|---------|
| 层数 N | 6 | 6 |
| 模型宽度 d | 512 | 1024 |
| MLP 隐藏层 d_ff | 2048 | 4096 |
| 头数 h | 8 | 16 |
| 每头维度 d_k = d_v | 64 | 64 |
| Dropout 率 | 0.1 | 0.3 |
| Label Smoothing | 0.1 | 0.1 |
| 训练步数 | 100,000 | 300,000 |

> **设计优势**：可调参数极少（层数、宽度、头数），其余按比例推算。BERT 和 GPT 基本沿用了这一架构，只需微调参数。

## 十、评价与总结

### 10.1 写作评价

- **优点**：极其简洁，每句话只讲一件事，信息密度高。
- **不足**：缺乏叙事性，未充分阐述设计理念和动机；对模型的解释较为欠缺。
- **建议**：写论文时应讲好故事，让读者有代入感；可将次要内容放入附录，正文聚焦核心思路和设计思考。

### 10.2 模型影响

1. **统一框架**：类似 CNN 对计算机视觉的统一作用，Transformer 为 NLP 提供了统一框架——无需为不同任务设计不同架构。
2. **跨领域通用**：从 NLP 扩展到图像、语音、视频，使不同领域的研究者使用同一"语言"，加速技术跨领域迁移。
3. **多模态融合**：不同模态的数据可通过同一架构抽取特征到相似的语义空间，为多模态大模型奠定基础。

### 10.3 局限与反思

1. **"Attention Is All You Need" 并不完全准确**：后续研究表明，Attention 主要负责序列信息的聚合，而 MLP 和残差连接同样不可或缺。去掉它们，Attention 几乎无法训练出任何东西。
2. **Attention 不建模顺序**：位置信息靠 Positional Encoding 显式注入，而非 Attention 本身处理。
3. **归纳偏置弱 → 需要更多资源**：Attention 的假设比 CNN/RNN 更一般化，对数据中结构的先验假设更少，因此需要**更多数据和更大模型**才能达到同等效果——这是现代 Transformer 模型越来越大的根本原因。
4. **启发新架构探索**：Attention 打破了"CNN/RNN 不可超越"的观念，后续出现了基于 MLP 等更简单架构也有不错表现的工作，未来可能会有更多新架构出现。

## 附录：核心概念速查表

| 概念 | 一句话解释 |
|------|-----------|
| **Self-Attention** | Query、Key、Value 均来自同一输入的注意力机制，每个位置可关注序列中所有位置 |
| **Scaled Dot-Product Attention** | Q·K^T / √d_k → Softmax → × V，最简单的注意力计算 |
| **Multi-Head Attention** | 将 Q/K/V 投影到 h 个子空间分别计算注意力，再拼接投影回来，模拟 CNN 多通道效果 |
| **Position-wise FFN** | 对每个位置独立作用的单隐藏层 MLP（512→2048→512） |
| **LayerNorm** | 对每个样本独立归一化，适合变长序列，比 BatchNorm 更稳定 |
| **Positional Encoding** | 用 sin/cos 函数生成位置向量，与 Embedding 相加以注入顺序信息 |
| **Masked Attention** | 将未来位置的注意力分数设为 -∞，Softmax 后权重为 0，保证自回归的一致性 |
| **Cross-Attention** | Decoder 的 Query 来自自身，Key/Value 来自 Encoder 输出，实现编码器到解码器的信息传递 |
| **Label Smoothing** | 将目标标签从 1.0 降为 0.1，牺牲 Perplexity 换取精度和 BLEU 提升 |
| **BPE** | 将词拆分为子词单元，减小字典规模，支持编码器与解码器共享 Embedding |
| **残差连接** | x + Sublayer(x)，缓解梯度消失，要求输入输出维度一致 |
| **自回归** | 解码器逐步生成输出，过去输出作为当前输入 |
