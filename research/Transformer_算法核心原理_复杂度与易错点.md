# Transformer 相关算法：核心原理、复杂度与易错点

> 适用范围：基于《Attention Is All You Need》及其中英翻译复现项目（见 `transformer_zh_en/`）。
> 本文只给「实现思路提示」，**不贴完整代码**。

---

## 1. BPE（Byte-Pair Encoding）子词分词

### 基本思想
从字符（或字节）出发，在训练语料上**反复合并出现频率最高的相邻符号对**，逐步构建一份「子词词表」，使罕见词能被拆成常见子词、常见词保持完整。

### 输入 / 输出
- **输入**：原始文本语料（清洗/归一化后）；目标词表大小 `V`。
- **训练输出**：`vocab`（子词集合）+ `merge_rules`（有序合并规则，记录每一步合并哪一对）。
- **编码输出**：`input_ids [B, S]`（整数序列），`<unk>` 仅在字符级都未见过时出现。

### 主要处理流程
1. 语料归一化（Unicode NFKC、统一空格表示，SentencePiece 用 `▁` 代空格）。
2. 每个词拆成字符序列，词尾加结束符。
3. 统计所有相邻符号对频次。
4. 取频次最高的一对合并，更新语料与频次表（用**优先队列/堆**维护）。
5. 重复至词表达到 `V` 或无可合并对。
6. 编码时按 `merge_rules` 顺序做**贪心最长匹配**合并。

### 时间 / 空间复杂度
- **训练**：约 `O(U·log V)`，`U` 为语料总符号数，`V` 为最终词表；用堆取最高频对为 `log V`。
- **编码**：单个词 `O(L·M)`，`L` 词长、`M` 合并步数；用合并秩（rank）表或 trie 可优化。
- **空间**：`O(V + 语料符号数)`；词表远小于 Word-level。

### 实现思路提示
- 用 `collections.Counter` + `heapq` 维护「最高频对」，合并后只更新受影响位置的相邻对计数。
- 编码用「从最高秩合并规则向下扫描」的贪心策略，而非从字符向上；可缓存每个词的合并结果。
- 保存 `merge_rules` 顺序，推理时必须用**同一份规则**，否则 ID 错位。

### 易错点与边界条件
- **Unicode 归一化遗漏**：同一字符不同编码（全角/半角、形近字）会被当成不同符号，词表膨胀 → 务必先做 NFKC。
- **空格表示**：中文/多语言务必用 `▁` 之类显式占位，否则词边界全丢失。
- **推理遇未见字符**：BPE 理论上字符级总有，但混合字节级（BBPE）才真正零 OOV；纯字符 BPE 遇新字符要回退到 `<unk>` 或字节。
- **合并秩平票**：频次相同时合并顺序会影响词表，需固定 tie-break（如按字典序）保证可复现。
- **最大长度**：编码后序列可能超过 `max_len`，需截断且**不能截断在子词中间导致非法 token**（保留完整子词或整体丢弃该样本）。

## 2. Scaled Dot-Product Attention

### 基本思想
用 Query 与所有 Key 做点积得到相似度，缩放后 Softmax 得到权重，对 Value 加权求和——一步即可让任意位置「看到」序列全局信息。

### 输入 / 输出
- **输入**：`Q [..., n, d_k]`、`K [..., m, d_k]`、`V [..., m, d_v]`、`mask`（可选）。
- **输出**：`attn_out [..., n, d_v]`（与 V 同维）。

### 主要处理流程
1. 计算相似度：`scores = Q·Kᵀ`（得到 `n×m`）。
2. 缩放：`scores / √d_k`。
3. 应用 mask（可选，见下）。
4. `weights = Softmax(scores, dim=-1)`。
5. `out = weights · V`。

### 时间 / 空间复杂度
- **时间**：`O(n·m·d_k)`；自注意力 `n=m` 时为 `O(n²·d)`。
- **空间**：注意力权重矩阵 `O(n·m)` 是显存大户；长序列时**平方级**增长，是 Transformer 核心瓶颈（后续有 FlashAttention、稀疏注意力等解法）。

### 实现思路提示
- 用单次矩阵乘法批量算所有 query（不要逐 token 循环）。
- mask 与 scores **同形**，直接相加；Softmax 沿最后一维。
- 推理阶段用 **KV-Cache** 缓存已算 K/V，避免每步重算历史。

### 易错点与边界条件
- **忘记缩放 √d_k**：`d_k` 大时点积值过大 → Softmax 趋近 one-hot → 梯度消失、训练不动。**这是最常见错误**。
- **mask 位置错误**：必须在 Softmax **之前**加 `-inf/-1e9`，之后加无效（Softmax 已归一化）。
- **mask 广播维度**：padding mask `[B,S]` 要扩成 `[B,1,1,S]` 才能和 `[B,h,S,S]` 分数相加；维度对不上会静默出错或被广播成错误形状。
- **数值溢出**：fp16 下 `exp` 易溢出，Softmax 内部建议先减最大值（`x - max(x)`）再用 fp32 计算。
- **因果掩码对角线**：第 `t` 位**允许看自己**（`t` 行只 mask `>t`），常见错误是把对角线也盖掉。

## 3. Multi-Head Attention

### 基本思想
把 Q/K/V 投影到 `h` 个低维子空间，并行算 `h` 次注意力，再拼接投影——让模型在不同表示子空间关注不同模式（类比 CNN 多通道）。

### 输入 / 输出
- **输入**：`Q,K,V [B, S, d_model]`、`n_heads h`。
- **输出**：`out [B, S, d_model]`（与输入同形，便于残差相加）。

### 主要处理流程
1. 用可学习 `W_Q,W_K,W_V` 把每个张量投影到 `[B, S, h, d_k]`（`d_k = d_model/h`）。
2. 转置为 `[B, h, S, d_k]` 以便逐头并行。
3. 每个头独立做 Scaled Dot-Product Attention。
4. 拼接 `h` 个头 → `[B, S, h·d_k] = [B, S, d_model]`。
5. 用 `W_O` 线性投影回 `d_model`。

### 时间 / 空间复杂度
- **时间**：`O(n²·d_model)`（与单头同阶，因 `h·d_k = d_model`），加投影 `O(n·d_model²)`。
- **空间**：`O(B·h·n²)`（每头一份注意力矩阵）。

### 实现思路提示
- `d_model` **必须能被 `h` 整除**，否则投影维度对不上（原论文 512/8=64）。
- 用 `view + transpose` 一次性 reshape 成多头，避免循环；合并头后再过 `W_O`。
- 可用「合并头维与批维」技巧把多头压成一次大矩阵乘（实现练习）。

### 易错点与边界条件
- **reshape 维度顺序**：`[B,S,h,d_k]` 与 `[B,h,S,d_k]` 转置易写反，导致头间信息串扰。
- **整除约束**：改 `d_model` 或 `h` 时要同时校验，否则运行时 shape 报错。
- **缩放因子**：多头内每个头的 `d_k` 变小，缩放应除以 `√d_k`（原论文用 `√d_model` 等价，因为 `d_k=d_model/h`，但实现里注意用的是子空间维度）。

## 4. Sinusoidal Positional Encoding（正弦位置编码）

### 基本思想
Attention 本身**无视顺序**（打乱输入顺序输出值不变，仅顺序变）。用固定/可学的「位置向量」加到词嵌入上，把时序信息注入数据。

### 输入 / 输出
- **输入**：序列长度 `n`、维度 `d_model`。
- **输出**：`pe [n, d_model]`（广播加到 `[B, S, D]`）。

### 主要处理流程
1. 对位置 `pos=0..n-1`、维度 `i=0..d/2-1`：
   - 偶数维：`sin(pos / 10000^(2i/d))`
   - 奇数维：`cos(pos / 10000^(2i/d))`
2. 与 `embedding × √d_model` 逐元素相加。

### 时间 / 空间复杂度
- **时间**：预计算 `O(max_len·d)`，推理时查表 `O(n·d)`。
- **空间**：`O(max_len·d)`，可缓存复用。

### 实现思路提示
- 用外层 `pos`、内层 `i` 的网格（`arange` 外积）一次性向量化生成，避免双重循环。
- 频率基底 `10000` 取对数后用 `exp` 生成，数值更稳定。
- 训练时加到 embedding 之后、送入第一层之前。

### 易错点与边界条件
- **奇偶索引错配**：`sin` 必须绑偶数维、`cos` 绑奇数维，写反位置信息全乱。
- **未乘 √d_model**：嵌入向量 L2 范数通常较小，位置向量幅度需匹配，否则位置信号被淹没（原论文对 embedding 乘 `√d_model`，PE 本身在 ±1 附近）。
- **外推失败**：固定 `max_len` 的正弦表在测试序列**超过训练长度**时无法直接查表（需插值或用 RoPE/ALiBi 等可外推方案）。
- **可学习 PE**：若用 `nn.Embedding` 学位置，最大位置必须 ≥ 实际序列长度，否则越界报错。

## 5. Beam Search 解码

### 基本思想
自回归生成时，每步保留 `B`（beam）条当前最优候选，扩展后按「累积得分 + 长度惩罚」重排，避免贪心陷入局部最优。

### 输入 / 输出
- **输入**：训练好的 Transformer（Decoder）、源序列、`beam_size B`、最大长度 `T`、长度惩罚 `α`。
- **输出**：一条最优目标序列（token id 列表）。

### 主要处理流程
1. 初始化 beam 为 `<bos>`，得分 0。
2. 每步：对 beam 中每条假设算下一 token 的 log softmax（用 KV-Cache）。
3. 展开 `B × V` 候选，按 `score/length^α` 取 top-`B`。
4. 遇 `<eos>` 的假设移入完成集（可继续保留至 beam 填满或达 `T`）。
5. 从完成集中选最高分序列输出。

### 时间 / 空间复杂度
- **时间**：每步 `O(B·V)`，`T` 步 → `O(B·V·T)`；`V` 是词表大小（可借 logits top-k 剪枝）。
- **空间**：`O(B·T)`。

### 实现思路提示
- 用堆/优先队列维护 beam，按「归一化得分」排序。
- 长度惩罚 `lp = ((5+T)/(5+1))^α` 抑制短序列偏好（原论文 α=0.6）。
- KV-Cache 按 beam 索引管理，扩展时复制历史缓存。

### 易错点与边界条件
- **未做长度惩罚**：beam 倾向过短译文，BLEU 偏低。
- **`<eos>` 处理**：第一条出 `<eos>` 不应立即终止（可能非全局最优），应移入完成集继续。
- **重复循环**：长生成易陷入 n-gram 重复，需加重复惩罚或 n-gram blocking。
- **padding/unk**： beam 中混入 `<pad>/<unk>` 应被屏蔽或降权。
- **batch 维错配**：beam 扩展后张量从 `[B,...]` 变 `[B*V,...]`，注意 reshape 回 `[B, V, ...]`。

## 6. Label Smoothing Cross-Entropy

### 基本思想
把 one-hot 硬标签放松为「正确类 0.9、其余均分 0.1」的软标签，用 KL 散度训练，降低模型过度自信、提升泛化与 BLEU。

### 输入 / 输出
- **输入**：`logits [B, S, V]`、`targets [B, S]`（pad 位置填 `-100` 忽略）。
- **输出**：标量 loss（仅在有效位置平均）。

### 主要处理流程
1. 构造平滑标签：`q(correct)=1-ε`，`q(other)=ε/(V-1)`。
2. 对 logits 算 log-softmax。
3. 与 `q` 做 KL 散度（等价于带平滑项的 CE）。
4. 忽略 `target == -100` 的位置后求均值。

### 时间 / 空间复杂度
- **时间**：`O(B·S·V)`（Softmax 过词表），与标准 CE 同阶，仅多一个平滑标签构造。
- **空间**：`O(B·S·V)` 是 logits 显存峰值（词表大时显著）。

### 实现思路提示
- 用 `nn.KLDivLoss(reduction='none')` + `log_softmax`，或框架自带 `LabelSmoothingLoss`。
- 先 `loss.masked_fill(target==-100, 0)` 再除有效 token 数（不能简单 `mean`，否则 pad 稀释梯度）。

### 易错点与边界条件
- **pad 未忽略**：`-100` 必须显式排除，否则 padding 位置计入 loss，模型学去预测 pad、BLEU 虚高。
- **平滑误用到忽略位**：`-100` 目标不应参与构造平滑标签，否则产生非法概率。
- **ε 取值**：原论文 0.1；过大（如 0.5）会让正确类信号过弱，收敛困难。
- **与 CE 等价性**：`ε=0` 应退化为标准 CrossEntropy，可用此做单测校验。

## 复杂度横向对照表

| 算法 | 时间复杂度 | 空间瓶颈 | 最易错点 |
|------|-----------|----------|----------|
| BPE 训练 | `O(U·log V)` | 词表+语料 | 归一化/空格/可复现 tie-break |
| Scaled Attention | `O(n²·d)` | `n×n` 注意力矩阵 | 漏 √d_k、mask 时机/广播 |
| Multi-Head | `O(n²·d)` | `B·h·n²` | reshape 转置、`d_model%h` |
| Sinusoidal PE | `O(n·d)` | `O(max_len·d)` | 奇偶错配、超长外推 |
| Beam Search | `O(B·V·T)` | `O(B·T)` | 长度惩罚、eos 早停 |
| Label Smoothing | `O(B·S·V)` | `O(B·S·V)` | pad 未忽略、均值口径 |

---

## 一句话总结
- **分词（BPE）** 解决「离散文本 → 可控词表 ID」；
- **Attention / Multi-Head** 解决「序列全局信息聚合」，复杂度平方级、缩放与掩码是命门；
- **Positional Encoding** 补回 Attention 缺失的时序；
- **Beam Search / Label Smoothing** 分别解决「解码质量」与「训练鲁棒性」，边界处理（pad 忽略、长度惩罚、eos）直接决定评测指标可信度。
